## Conventions established

- **Editing `.docx`/`.pptx` in this repo: use loss-less surgical XML swap, NOT pandoc regeneration or a python-docx rebuild.** The deliverables are Word-authored and no pandoc style template exists, so regeneration changes formatting/letterhead. Correct method: treat the file as a zip, rewrite only the text-bearing `word/*.xml` (or `ppt/slides/*.xml`) byte-streams for the exact literal, preserve member order/compression, replace atomically, then verify per-file zero-residual + `textutil` run-reconstruction (Word can split a token across runs, so a raw XML scan can miss it). Always check embedded comments/tracked changes first (docx-handling skill); never commit/push docx without explicit permission (auto-push hook is live).
- **Brand rule beats generic skill guidance on the website.** Brand Guidelines v1.4 bans motion (§3.5) and uses restrained gold-underline text CTAs, not filled buttons.
